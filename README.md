# 金狐开单系统 (Jinhu Order System)

> 为广告公司、图文店、中小商户打造的开源自部署订单管理 ERP。
> 由长沙金狐文化在真实业务中打磨多年，从 3.7GB 内存的玩客云矿渣，到斐讯 N1，再到群晖 NAS 和普通云主机都能跑。

![PHP](https://img.shields.io/badge/PHP-7.4%20~%208.x-8892BF) ![MySQL](https://img.shields.io/badge/MySQL-5.6%2B%20%7C%20MariaDB%2010%2B-4479A1) ![License](https://img.shields.io/badge/License-MIT-green) ![部署](https://img.shields.io/badge/%E9%83%A8%E7%BD%B2-%E8%87%AA%E6%89%98%E7%AE%A1-blue)

一台百元级的旧设备 + 这套系统，就能管好一家广告公司的全部订单、客户和账。**无需云服务、无订阅费、数据 100% 在自己手里。**

---

## ✨ 功能特性

**订单开单**
- PC / 手机端双端开单，手机上随时随地接单查单
- 按平方米 / 按件 / 按米混合计价，填尺寸自动算平方数（金额 = 平方数 × 数量 × 单价）
- 订单状态流转：待确认 → 已确认 → 生产中 → 已完成，支持批量打印销售单（自动适配平方数列）
- 商品图 / 凭证图片上传（`fileinfo` 扩展可选，低配环境自动降级）

**客户与商品**
- 客户档案、联系人与历史订单一键直达
- 产品 / 分类 / 单位管理，同客户历史价自动参考

**财务管理**
- 收款登记（支持优惠联动：金额 = 未收 − 优惠）、支出登记（支持凭证上传）
- 客户对账单、欠款统计、收支报表，Excel / PDF 导出
- 收支流水按年月汇总，年度累计一目了然

**数据与安全**
- 自动备份数据库，备份文件 AES 加密，一键下载 / 恢复
- 全站预编译 SQL、输出转义、CSRF Token、登录失败锁定、安全响应头（CSP 等）
- 会话安全：HttpOnly + SameSite，登录后重生成会话 ID

**低配友好（作者的偏执）**
- 实测跑在 Amlogic S805 玩客云（4 核 A5 / 3.7GB 内存）+ PHP 7.4 + MySQL 5.6 上，100 人并发无压力
- 斐讯 N1 固件版实测 300 并发 0 错误（见下方固件板块，刷机即用）
- 群晖 NAS / 宝塔 / 1Panel / 普通虚拟主机均可部署
- 无框架、无 Node 构建、无第三方服务依赖，上传即用

## 🚀 快速开始（3 分钟安装）

### 环境要求

| 项目 | 要求 |
|---|---|
| PHP | 7.4 ~ 8.x，需 `pdo_mysql` `mbstring` `openssl` `json` `gd`（`fileinfo` 可选） |
| 数据库 | MySQL 5.6+ 或 MariaDB 10+ |
| Web | Nginx / Apache，指向本目录即可 |
| 硬件 | 1 核 512MB 内存起步（内含 tcpdf 与 PHPExcel 类库，已内置 vendor，无需 Composer） |

### 安装步骤

1. 将本目录**全部文件**上传到网站根目录（保持目录结构）
2. 浏览器访问 `http://你的地址/install.php`，按向导填写数据库信息和管理员账号
3. 安装程序自动完成：建库建表 → 生成 `config.local.php`（含随机备份加密密钥）→ 落安装锁
4. 登录后台即可使用（内置演示数据，正式使用时可删除）

> **宝塔用户**：新建站点 → 上传解压 → 访问 `/install.php`，完事。
> **群晖用户**：Web Station 新建 PHP 网站 → 上传文件 → 访问 `/install.php`。
> **玩客云 / N1 / 旧电脑**：见[矿渣改造实录](https://www.jinhuwh.vip/gongsi/53.html)，含刷机与部署全过程。

### 演示数据

首次安装会自动生成一批演示订单 / 客户 / 收支记录（金额均经过验算），方便快速上手体验；正式使用时在后台直接删除即可。

## 📦 N1 固件版：刷机即用，开机就有整套系统

**不想配环境？** 我们为斐讯 N1（Amlogic S905D）制作了**开箱即用固件**：Armbian + Nginx + PHP 8.2 + MySQL 5.6 + 宝塔面板 + 本系统，全部预装、调优、安全加固完毕，写入 eMMC 即为生产可用。

| 项目 | 说明 |
|---|---|
| 适用设备 | 斐讯 N1 盒子（**8G / 16G / 32G / 128G eMMC 全系可刷**） |
| 镜像大小 | 压缩包约 1.7 GB，解压 7 GiB（专为 8G 小盘机型做的瘦身布局） |
| 首次开机 | 自动扩容占满整盘 → 重置设备身份 → **随机化所有密码** → 清理痕迹，凭据写入 `/root/首次启动报告.txt` |
| 性能实测 | **300 并发 0 错误**，<100 用户近乎瞬时响应（eMMC + OPcache+JIT） |

**三步刷机**（在已运行 Armbian 的 N1 上，全程约 5 分钟）：

```bash
sha256sum -c n1-jinhu-firmware-slim-*.img.zst.sha256    # 1. 校验
zstd -d n1-jinhu-firmware-slim-*.img.zst                # 2. 解压
dd if=n1-jinhu-firmware-slim-*.img of=/dev/mmcblk2 \
   bs=4M status=progress conv=fsync && reboot           # 3. 写入 eMMC 并重启
```

## 🧮 计价规则说明

- 按面积计价的商品：填写长宽（米），系统自动算出单张平方数，金额 = **平方数 × 数量 × 单价**
  例：6×5 米写真 1 张，单价 40 元/㎡ → 30 × 1 × 40 = 1200 元
- 按件 / 按米计价：金额 = 数量 × 单价
- 打印销售单时：本单存在按平方计价商品则自动显示"平方数"列并合计，否则不显示

## 📊 匿名使用统计与检查更新（透明声明）

本系统包含**可选**的匿名统计与版本检查功能，作者承诺：

- **默认关闭**，仅在安装时你主动勾选、或管理员在后台开启后才会生效
- 每周最多上报一次，内容仅为：随机实例 ID、系统版本号、PHP 版本、MySQL 版本
- **绝不上报**订单、客户、金额、备注等任何业务数据
- 随时在 `系统设置 → 关于与更新` 中一键关闭
- 实现代码完全公开（`telemetry.php`，约 150 行），接受任何人审计
- 不想要？**直接删除 `telemetry.php` 即可**，系统照常运行（相关入口自动隐藏）
