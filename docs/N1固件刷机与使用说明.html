二、刷机前准备

硬件

  • 斐讯 N1 盒子一台（8G / 16G / 32G / 128G eMMC 均可）
  • N1 已能启动 Armbian（U盘或 eMMC 均可）；若还是安卓系统或已变砖，见「方式 B」

软件

工具用途 / 获取
zstd解压 .zst；Armbian 内置 apt install zstd，Windows 用 7-Zip 23+
sha256sum / Get-FileHash校验镜像（系统内置）

镜像文件

  • n1-jinhu-firmware-slim-20260929.img.zst（约 1.7 GB）
  • n1-jinhu-firmware-slim-20260929.img.zst.sha256（校验文件）
⚠️ 本镜像为 raw dd 格式，不能用 USB Burning Tool 直接烧录（它只认 aml 升级包）。刷机会清空整块 eMMC，请先备份。

三、刷机步骤

方式 A（推荐）：在已运行 Armbian 的 N1 上刷入

步骤 1：下载并校验镜像

wget https://gitee.com/jinhuwh/jinhu-order-system/releases/.../n1-jinhu-firmware-slim-20260929.img.zst
wget https://gitee.com/jinhuwh/jinhu-order-system/releases/.../n1-jinhu-firmware-slim-20260929.img.zst.sha256
sha256sum -c n1-jinhu-firmware-slim-20260929.img.zst.sha256   # 必须输出 OK

步骤 2：解压（需约 7 GB 剩余空间）

zstd -d n1-jinhu-firmware-slim-20260929.img.zst
# 得到 n1-jinhu-firmware-slim-20260929.img（7 GiB）

步骤 3：写入 eMMC（⚠️ 此步之后原系统即被覆盖）

# N1 的 eMMC 设备为 /dev/mmcblk2
dd if=n1-jinhu-firmware-slim-20260929.img of=/dev/mmcblk2 bs=4M status=progress conv=fsync
sync
reboot   # 拔掉U盘（如在U盘系统）后重启

写入约 3-6 分钟。之后进入「四、首次开机自动初始化」。

方式 B：全新 N1（安卓系统）或已变砖

  1. 先用 USB Burning Tool 线刷任意 Armbian ophub 版（社区通用教程，关键词「N1 刷 Armbian」）救到能启动 Linux
  2. 再按 方式 A 刷入本固件

四、首次开机：自动初始化 + 自动扩容

第一次开机会自动执行初始化脚本（/root/n1-firstboot.sh，约 1-2 分钟），共 8 步：

步骤动作
1根分区自动扩容：7GiB 布局扩展到整块 eMMC（8G/16G/32G/128G 自适应），文件系统在线扩容
2重置设备身份（machine-id + SSH host key 重新生成）
3随机化系统 root 密码
4随机化开单系统 admin 密码
5随机化 MySQL root 密码
6随机化宝塔面板端口、安全入口、密码
7清理日志与操作痕迹
8重建 2GB 交换分区，自我禁用

凭据获取：在 N1 本机（HDMI + 键盘）登录 root，执行：

cat /root/首次启动报告.txt
📌 随机化的密码只在 /root/首次启动报告.txt 中出现一次，请立即记录，登录后第一时间修改所有密码。若 root 无法登录，可单用户模式重置或重新刷机。

六、常见问题

Q1：我的 N1 是 8G 存储，能刷吗？

✅ 能。镜像布局 7 GiB，为 8G eMMC（实际可用约 7.2-7.3 GiB）预留安全余量，首开自动扩容吃满全部空间。

Q2：16G/32G 刷完浪费空间？

不会，自动扩容会扩展到整块 eMMC。

Q3：能用 USB Burning Tool 直接烧吗？

❌ 不能。它只认 aml 升级包。全新机器按「方式 B」先线刷 Armbian 再刷本固件。

Q4：刷机后无法开机 / 卡开机画面

  • 多为原机 u-boot 被覆盖或分区错位：Burning Tool 线刷 Armbian ophub 包救回后重刷
  • 检查电源（N1 需 12V/2A）
  • 8G 机型请确认下载的是 slim 瘦身版

Q5：开机后 88 端口打不开

  • 首次开机 1-2 分钟内初始化未完成，稍等再试
  • systemctl status nginx php-fpm-82、ps aux | grep mysqld、tail -50 /www/wwwlogs/*.error.log

Q6：忘记密码

  • MySQL root：宝塔 → 数据库 → root 密码
  • admin：宝塔 phpMyAdmin 改 users 表
  • 宝塔密码：N1 本机 bt 5 重置
  • root：单用户模式重置

Q7：恢复出厂

rm -f /var/lib/jinhu-firstboot.done
reboot

Q8：SSH 提示 host key 变更

正常（每台设备独立密钥），本地执行 ssh-keygen -R <N1的IP> 即可。

Q9：需要 PHP 8.1

宝塔面板 → 软件商店 → PHP 8.1 → 安装（约 2 分钟）。

Q10：打开 phpMyAdmin 报 Function utf8_encode() is deprecated

镜像内置的 phpMyAdmin 5.1.1 与 PHP 8.2 不兼容导致，只影响 phpMyAdmin 这个可选的数据库网页工具，开单系统与命令行 mysql 不受影响。修复任选其一：宝塔「软件商店 → phpMyAdmin」升级到 5.2.x；或 SSH 执行一行修复（保留原配置与随机入口目录，执行后刷新页面重新登录）：

cd /tmp && wget -q https://files.phpmyadmin.net/phpMyAdmin/5.2.1/phpMyAdmin-5.2.1-all-languages.zip && unzip -q phpMyAdmin-5.2.1-all-languages.zip && E=$(ls -d /www/server/phpmyadmin/phpmyadmin_*/) && cp ${E}config.inc.php /tmp/pma.cfg && rm -rf "${E:?}"* && cp -a phpMyAdmin-5.2.1-all-languages/. $E && cp /tmp/pma.cfg ${E}config.inc.php && mkdir -p $E/tmp && chown www:www $E/tmp && systemctl reload php-fpm-82

七、安全建议（首次登录后立即执行）

  1. 修改 root 密码：passwd
  2. 修改宝塔密码：面板 → 设置
  3. 修改开单系统 admin 密码：系统内 → 个人设置
  4. 修改 MySQL root 密码：宝塔 → 数据库
  5. 配置防火墙：仅放行 88 + 宝塔端口，SSH 改非标端口或限来源 IP
  6. 开启 HTTPS
  7. 定期备份：数据库 + 站点文件
